# Security Policy

## Supported Versions

Security fixes for this website are applied to the latest code on the `main`
branch. Older revisions are not maintained separately.

## Reporting a Vulnerability

Report suspected security vulnerabilities privately to
[bitcoinq@btq.com](mailto:bitcoinq@btq.com).

Include the affected page or component, steps to reproduce the issue, its
potential impact, and any relevant proof of concept. Do not include passwords,
private keys, or other secrets.

Please avoid posting vulnerability details in public issues or pull requests.
Allow the maintainers time to investigate and coordinate a fix before publicly
disclosing the issue.
